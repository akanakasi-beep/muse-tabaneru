# tabaneru — 束ねる作法スキル

使い捨てのサイドチャットやサブエージェント（糸）を、仕事を失わずに束ねるための Muse スキル。

束ねの中心はチャット管理ではなくファイル管理。状態・収穫・引き継ぎは全部ファイルに置き、糸が終わっても次の手はファイルを読んで始める。

## 考え方

- 糸は使い捨ての読み書きの口。チャットの文脈は正本ではないし、記憶の置き場でもない。
- 一つの仕事に一つのフォルダ。糸は自分の区画だけを書く。
- 消さない。畳む。終わった糸は索引で「畳んだ」になり、区画は残る。収穫ゼロも一行残す（不在の開示）。
- 引き継ぎは束ね役が作る。欄：済んだこと／収穫／未済・持ち越し／判断待ち／逐語（証拠になる言葉だけ）／次の手へ／不在の開示。
- 糸の収穫が正本になるのは、束ね役が検分して家の頁に置いた時だけ。

## 導入

`SKILL.md` と `skill.yaml` を Muse のカスタムスキルフォルダ（`~/workspace/custom-skills/tabaneru/`）に置く。

## 由来

連盟《余白》（Yohaku）の複合実験（2026-11-23開始）で実測しながら作った作法。同じ日に立てた二本の糸で「声の渡り方」が違ったこと、糸自身が「ファイルに置く形が要る」と述べたことが、設計の根拠になっている。関連：検品スキル [muse-kenpin](https://github.com/akanakasi-beep/muse-kenpin)。
